# 严格模式 / 遮罩：按键与计时用例

本清单描述**每种配置下用户应当看到的行为**，用于休息遮罩、键盘屏蔽与计时一致性的人工回归。

## 阅读前提

遮罩窗体不获取键盘焦点（`WS_EX_NOACTIVATE`），因此休息期间的所有按键行为都由全局键盘钩子决定，与窗体焦点无关。**不声明运行模式的用例无法判定结果**——同一条用例在下面四种模式下结论可能相反。

### 运行模式

| 模式 | 允许跳过 | 严格模式 | 键盘行为 |
|---|---|---|---|
| **M1**（默认） | 是 | 是 | 所有按键不生效；裸 Esc / 裸 空格 = 跳过 |
| **M2** | 是 | 否 | 仅裸 Esc / 裸 空格 被拦截用于跳过，其余按键正常输入 |
| **M3** | 否 | 是 | 拦截 Win / Alt+Tab / Alt+F4 / Ctrl+Esc，其余按键正常输入 |
| **M4** | 否 | 否 | 不安装钩子，键盘完全正常 |

「裸按键」指不按任何修饰键（Ctrl / Alt / Shift 均未按下）。Shift+Space、Ctrl+Space、Alt+Space、Shift+Esc 都不视为跳过。

## A 组：休息遮罩期间的按键行为

| ID | 模式 | 步骤 | 预期 |
|---|---|---|---|
| A1 | M1 / M2 / M3 | 按 Alt+Space | 不结束休息；M1 下窗口系统菜单也不出现 |
| A2a | M1 / M2 | 按 Ctrl+Space | 不结束休息 |
| A2b | M1 / M2 | 按 Shift+Space | 不结束休息（避免与输入法全角/半角切换冲突） |
| A2c | M1 / M2 | 按 Shift+Esc | 不结束休息 |
| A3 | M1 / M2 | 按住空格 3 秒 | 只跳过**一次**，不因按键自动重复而连续触发 |
| A3b | M1 / M2 | 承 A3，观察跳过之后 1 秒内继续按键 | 按键**不得**输入到下层程序（跳过瞬间仍按住的键，其重复消息必须被拦截，直到物理抬起） |
| A4 | M1 / M2 | 按裸空格 | 结束休息，且只结束一次 |
| A4b | M1 / M2 | 按裸 Esc | 结束休息（与空格等效） |
| A5 | M3 / M4 | 按裸 Esc | **不**结束休息（该模式未开启跳过） |
| A6 | M1 | 按 Alt+F4 | 遮罩不消失，进程不退出 |
| A6 | M3 | 按 Alt+F4 | 遮罩不消失 |
| A6 | M2 | 按 Alt+F4 | 遮罩不消失（按键落到用户自己的前台窗口，该窗口可能被关闭，属该模式的合理代价） |
| A7a | M1 | 按 Alt+Tab / Ctrl+Esc | 无法切换窗口，遮罩保持最前 |
| A7b | M2 | 按 Alt+Tab | **允许**切换窗口，但遮罩必须仍覆盖在最上层。若被同样声明为置顶的第三方窗口（全屏播放器、录屏工具等）盖住，记为观察项——置顶层级只能保证顺序，无法保证压过所有竞品窗口 |
| A8a | M1 / M3 | 按 Win 单键 | 开始菜单不弹出 |
| A8b | M3 | 按菜单键（VK_APPS） | 已知限制：下层程序会弹出右键菜单，但被置顶遮罩挡住不可见。不算失败 |
| A9 | M1 / M2 | 输入法正在组词时按空格 | 已知限制：会被判为跳过（钩子在按键层拦截，输入法看不到该按键）。休息期间按空格本身即表达「跳过」意图 |
| A10 | 全部 | 点击遮罩本身 / 尝试点击遮罩以外区域 | 焦点不转移；遮罩覆盖整屏（含任务栏），不存在「遮罩以外区域」 |
| A11 | M1 / M2 | 跳过之后立即继续打字 | 按键正常输入到原窗口；仅 A3b 描述的瞬间仍按住的键除外 |

补充：若跳过时用户仍按着跳过键，程序会持续吞掉该键的重复消息，直到收到抬起；若抬起事件丢失（切换安全桌面、远程桌面断连、拔出键盘等），最多 8 秒后强制恢复键盘。

## B 组：计时一致性

| ID | 步骤 | 预期 |
|---|---|---|
| B1 | 工作倒计时中锁屏 4 分钟再解锁 | 剩余时间减少约 **3 分钟**（等于「离开暂停」阈值），而不是 4 分钟；解锁后托盘提示「检测到离开，计时已暂停」，动一下鼠标即恢复 |
| B1b | 同上，锁屏 2 分钟（短于阈值） | 照常计时，剩余减少约 2 分钟；托盘不显示暂停态 |
| B1c | 把「离开多久后暂停」设为 0，锁屏 10 分钟 | 不暂停，照常扣满 10 分钟 |
| B2 | 工作倒计时中休眠 10 分钟再唤醒 | 剩余时间与休眠前相差不超过数秒，不补算；不出现「唤醒即弹休息」 |
| B2b | 边角：阈值为 0 且休眠前剩余 1 秒 | 唤醒后第一次计时即弹出休息（已知边角，允许） |
| B3 | 休息倒计时中锁屏 1 分钟（休息总长 20 秒） | 休息在锁屏期间照常走完并记为完成（锁屏即人不在屏幕前，视作真实休息）；解锁后遮罩已消失、托盘回到工作倒计时 |
| B3b | 承 B3，注意听 | 结束音在锁屏期间播放，解锁后听不到。**不是缺陷** |
| B4 | 倒计时中把系统时间前/后调 1 小时 | 不崩溃、不跳秒、不出现负数倒计时 |
| B5 | 连续运行跨越系统计时器回绕点（约 49.7 天） | 不崩溃，离开检测判定不错乱 |
| B6 | 休息中拔掉显示器 | 不崩溃、不残留窗体、进程存活 |
| B6b | 承 B6，重新插回显示器 | **下一次**休息时遮罩位置正确（本次休息内不重建，新屏本次可能没有遮罩，允许） |
| B6c | 休息中插上一块新显示器 | 新屏本次没有遮罩；下一次休息正常覆盖 |

## C 组：已知限制（验证优雅降级即可）

| ID | 步骤 | 预期 |
|---|---|---|
| C1a | 前台是提权程序（以管理员运行）时进入休息 | 拆成四项分别判定，见下方「C1a 分项判定表」——**不要合成一个总结论** |
| C1b | UAC 弹窗 / Ctrl+Alt+Del / 锁屏界面 | 屏蔽失效，属操作系统的安全桌面机制，无法拦截；只要求不崩溃、不误判、返回后遮罩仍在、倒计时正确 |
| C2 | 安全软件拦截键盘钩子导致安装失败 | 必须出现**一次**托盘气泡提示，文案按「允许跳过」开关分两种；倒计时仍正常结束休息 |
| C3 | 遮罩弹出时输入法正在组词 | 不抢焦点，未上屏内容不丢失 |

### C1a 分项判定表

准备：以管理员身份启动一个记事本或命令提示符，让它保持焦点，然后等待休息弹出。

| 项 | 观测点 | 通过 | 推翻 |
|---|---|---|---|
| C1a-1 按键拦截 | 在提权窗口中按 `aaaaa`，休息结束后看是否落入 | 未落入 | 落入 → 提权场景下屏蔽失效 |
| C1a-2 遮罩覆盖 | 休息期间观察遮罩是否完整盖住提权窗口 | 完整覆盖 | 被盖住 → 单独记录（与按键拦截无关） |
| C1a-3 跳过可用 | 按裸空格 / 裸 Esc | 正常结束休息 | 无响应 → 单独记录 |
| C1a-4 系统键 | 按 Win 单键 | 开始菜单不弹出 | 弹出 → 单独记录 |

**四项任一失败都必须单独记录，不得合并成一条总结论。** 遮罩是否置顶与按键是否被拦截是两套独立机制，存在「按键拦住了但遮罩被盖住」这种部分成立的情况；合成一条会把它判成整体失败，之后每一次排查都会被这条错误的结论带偏。

**判据来源说明**：「键盘屏蔽不受提权影响」目前是**源码级推论**（低级键盘钩子在原始输入层回调，不注入目标进程，因而不经过窗口消息的完整性级别检查），首次实测之前不得当作既成事实引用。

**无论实测结果如何，都要回看 README 里关于提权场景的表述是否与实测一致**：若实测证明屏蔽生效，说明当前表述低估了自身能力（用户会因为那句话在提权场景下不敢依赖此功能），必须改写；若实测证明失效，则该表述成立，但要把结论来源标注为实测而非推论。两个方向都需要动作，不存在「测完就完事」的情况。

## 观察项纪律

**任何「不应发生 X」的断言都是观察项，不能作为通过判据。** 「没有看到」与「没有测到」无法区分，把它当通过条件会让清单永远变绿。

因此，凡是只能通过「什么都没发生」来验证的行为（例如「某提示不应出现」），一律记为观察项：保留记录、参与人工判断，但不计入通过率。

以下条目属于会议检测能力，当前版本未启用，保留备查。

| ID | 步骤 | 预期 |

| M-1 | 会议结束（摄像头、麦克风全部释放） | 托盘保持「会议中」约 60 秒后才恢复提醒。**该滞后是设计**：摄像头时间戳存在秒级抖动，退得太快会让提醒在散会期间反复弹出；60 秒后仍未恢复才是缺陷 |
